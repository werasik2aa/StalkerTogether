Как подключиться к серверу

1. Скачайте чистый Anomaly 1.5.3 MODDB.

2. Скачайте Anomaly Together.

3. Распакуйте Anomaly Together в папку с игрой.

4. Запустите игру, нажмите → Подключение по IP.

5. Убедитесь, что сервер запущен.

6. Используйте IP хоста или из RadminVPN / Hamachi / ZeroTier / Portmap.io / Ngrok / Openport.io / Playit.gg.

6*. Для игры через Steam → Shift + Tab → примите приглашение друга.

7. Нажмите → OK → Играйте.

8. В левом углу увидите "Connected as client" → вы подключены к серверу.

Как создать сервер

1. Скачайте чистый Anomaly 1.5.3 MODDB.

2. Скачайте Anomaly Together.

3. Откройте входящий порт 44139 GUIDE.

4. Запустите игру → создайте или загрузите профиль.

5. В левом углу увидите "Connected as host" → сервер запущен.

6. Поделитесь своим IP или из RadminVPN / Hamachi / ZeroTier / Portmap.io / Ngrok / Openport.io / Playit.gg.

6*. Для игры через Steam → Shift + Tab → отправьте приглашение друга.

7. Вы можете настроить сложность если хотите.

8. Снимите с паузы игру → Играйте.
