Faq how to use mod

Connect To Server

1. Download clear S.T.A.L.K.E.R. Anomaly 1.5.3 using this links: MODDB
2. Download Anomaly Together mod.
3. Unpack downloaded S.T.A.L.K.E.R. Anomaly 1.5.3 archive using 7-Zip to some folder.
4. Unpack Anomaly Together mod archive using 7-Zip to the folder with Anomaly 1.5.3 applying any replacements.
5. Open inbound port 44139 - if you want to host a server! GUIDE.
6. Open game with Anomaly Launcher
7. In Main Menu you have to click Connect using IP
8. Paste HOST's IP from your private room of RadminVPN or Hamachi. Or Dedicated ip for you from Playit.gg | portmap.io | zerotier.
9. Type any Nickname (Login) and click ok
10. If host is available and already waiting for you in-game, you will be connect to server from latest save or it will ask for new profile.

Create Server

1. Download clear S.T.A.L.K.E.R. Anomaly 1.5.3 using this links: MODDB
2. Download Anomaly Together 2.1 mod from: Here.
3. Unpack downloaded S.T.A.L.K.E.R. Anomaly 1.5.3 archive using 7-Zip to some folder.
4. Unpack Anomaly Together mod archive using 7-Zip to the folder with Anomaly 1.5.3 applying any replacements.
5. Open inbound port 44139 - if you want to host a server! GUIDE.
6. Open game with Anomaly Launcher
7. Create new profile as usual.
8. When you are in game, at the left you should see notification server started as HOST (if not, check it in PDA's message log, if not, restart the server, if not, reinstall mod)
9. If your ip is behind NAT. Use one of that tools: "RadminVPN | Hamachi | Playit.gg | portmap.io | zerotier" to share ip with your friend.
10. Wait for friends...
