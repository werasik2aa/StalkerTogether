Spawning and destroying objects functions

alife_create_client(section, position, lv_id, gv_id, id_parent)

This function used to spawn object remotely on host side from client without await him.
That send spawn entity request to host. Host spawn object.

Example: alife_create_client("box", db.actor:position(), 0, 0)

alife_create_awaite(functa, section, position, lv_id, gv_id, id_parent)

This function used to spawn object remotely on host side from client with await him.
That send spawn entity request to host. Host spawn object. Client catch event and calls functa(se_object)

Example: 
            {
              alife_create_awaite(function(se)
                if se then -- just for?
                  log("Object box spawned: "..box:section_name())
                end
              end, "box", db.actor:position(), 0, 0)
            }
            {
              alife_create_awaite(function(se)
                if se then -- just for?
                  log("Object bolt spawned in parent actor")
                end
              end, "bolt", VEC_ZERO, 0, 0, db.actor:id())
            }

alife_release_client(se_object)

This function used to despawn object remotely on host side from client by se_object
That send despawn entity request to host. Host despawn object.

Example: alife_release_client(alife_object(55))

alife_release_client_id(id)

This function used to despawn object remotely on host side from client by id
That send despawn entity request to host. Host despawn object.

Example: alife_release_client_id(55)

TeleportPlayer(u32 NetID, Fvector Position)

This function used to teleport player to position. IT'S HOST ACTION!
Check lua_help_mp.lua for understand what you want to do 

            {
              local GameManager = SteamGameManager()
              local PlayerManager = GameManager:GetPlayerManager()
              local pdata = PlayerManager:GetPlayerDataAtIndex(1) -- HOST IS 0
              if pdata then
                local id = pdata:GetNetID()
                local pos = db.actor:position()
                PlayerManager:TeleportPlayer(id, pos)
              end
            }

KickPlayer(u32 NetID)

This function used to teleport player to position. IT'S HOST ACTION!
Check lua_help_mp.lua for understand what you want to do

Example: 
            {
              local GameManager = SteamGameManager()
              local ServerSOSOCK = SteamServer()
              local PlayerManager = GameManager:GetPlayerManager()
              local pdata = PlayerManager:GetPlayerDataAtIndex(1) -- HOST IS 0
              if pdata then
                local id = pdata:GetNetID()
                PlayerManager:KickPlayer(id)
              else
                local NETid = ServerSOSOCK:get_player_by_index(1) -- HOST IS 0
                PlayerManager:KickPlayer(NETid)
              end
            }

OnCustomSound(LPCSTR Name, Fvector pos, CSE_Abstract* obj) or OnCustomSound(LPCSTR Name, Fvector pos, u16 obj)

This function used to sync sound with clients.
Check lua_help_mp.lua for understand what you want to do

Example: 
            {
              local GameManager = SteamGameManager()
              xr_effects.play_sound = function (actor, obj, p)
                  xr_effects.set_sound_play(actor, obj, p)
                  local sobj = alife_object(obj:id()) or alife():actor()
                  if not IIsHost() then
                      GameManager:OnCustomSound(p[1], sobj and sobj.position or vector():set(0, 0, 0), sobj)
                  end
              end
            }
